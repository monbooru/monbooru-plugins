# Third-party clients

> **Assume nothing in this table has been reviewed.**
> Read the source before you install a client.

| name | what it does | maintainer | source |
| --- | --- | --- | --- |
| Unofficial MonSender Android | Sends Android links to MonLoader's download queue. | IkariDevGIT | [UnofficialMonsenderAndroid](https://github.com/IkariDevGIT/UnofficialMonsenderAndroid) |
| Boorusphere (Schw1's fork) | Browses booru sites, including Monbooru; sends posts via MonLoader. | Schw1 | [boorusphere](https://github.com/Schw1/boorusphere) |

`source` is a public repo. `maintainer` is the account that maintains the client.

## Row rules

- Link a public source.
- One row per client, one line, description short enough to read at a glance.
- An entry whose repo is gone will be removed.
