# Contributing

See [monbooru's CONTRIBUTING](https://github.com/monbooru/monbooru/blob/main/CONTRIBUTING.md);
it covers all the monbooru repos, including this one.

Open issues for the registry and the examples here.  
A bug in a listed plugin or theme goes to its own tracker.  
A bug in the contract itself (pairing, the relay call, the plugin mount, the theme variables) goes to
[monbooru](https://github.com/monbooru/monbooru/issues).
